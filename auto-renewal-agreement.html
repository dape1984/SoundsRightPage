SoundsRight 自动续费服务协议

生效日期：2026年5月19日 · 适用应用：SoundsRight（耳顺英语）

请您务必审慎阅读。本协议适用于 SoundsRight Pro 月度会员与年度会员（自动续期订阅）。终身会员为一次性购买，不适用自动续费。开通前，应用内购买页面会向您展示付费金额、续费周期、取消方式等关键信息；您须主动勾选同意本协议及相关说明后方可支付——我们不会默认开通或默认同意自动续费。

一、协议范围与关联文件

本协议是 《会员服务说明》 的补充。您使用自动续费服务，即表示已阅读并同意本协议、会员服务说明、隐私政策 及应用商店相关规则。

二、自动续费服务说明

  1. 服务性质：您购买的是「自动续期订阅」类商品，系统在订阅周期届满时，通过华为应用内支付（或您所使用的 Apple/Google 等渠道）自动发起下一周期费用扣款，使 Pro 会员服务延续。
  2. 适用商品：
    • 月度会员：续费周期为 每 1 个自然月（以应用商店计费规则为准）；
    • 年度会员：续费周期为 每 12 个自然月（以应用商店计费规则为准）。
  3. 付费金额：开通时及每次续费时实际扣款金额，以购买页面及收银台实时显示为准；应用内亦会在显著位置展示价格与周期。若存在优惠活动或价格调整，我们将按应用商店要求以清晰、显著方式告知。
  4. 付费后获得的服务：详见 《会员服务说明》 第三节「Pro 会员权益」。

三、开通流程与用户同意

  1. 您在应用内选择月度或年度会员；
  2. 阅读购买页展示的价格、续费周期、取消路径及本协议链接；
  3. 主动勾选「已阅读并同意《会员服务说明》《自动续费服务协议》」等确认项（系统不会预先勾选）；
  4. 在二次确认弹窗中点击「同意并支付」后，进入华为 IAP / 应用商店收银台完成支付；
  5. 支付成功后，当期 Pro 会员立即或按平台规则生效。

未经您上述明确同意，我们不会为您开通自动续费。

四、续费、扣款时间与告知

  1. 续费时间：通常在当期订阅届满前，由应用商店（如华为应用市场）按周期自动扣款；具体扣款时点以华为 IAP 及华为帐号账单规则为准。
  2. 续费价格：若无另行公示，续费价格与当期订阅价格一致；价格变动时，按华为等平台规则提前通知或征得同意。
  3. 续费前告知：华为等渠道可能通过应用市场通知、华为帐号消息等方式在续费前向您提示；请您保持关注。我们亦会在应用内购买页持续公示关键信息。
  4. 扣款失败：若余额不足或支付失败，续费可能中止，Pro 权益可能在当期届满后终止，直至您成功续费或重新购买。

五、如何解除自动续费（退订）

您可随时解除自动续费；解除后下一周期不再扣款，已付费的当期权益保留至周期结束。

华为应用市场渠道（推荐路径）：

  1. 打开华为手机上的「应用市场」；
  2. 进入「我的」→「付款与账单」；
  3. 打开「订阅」或「连续订阅」管理；
  4. 找到 SoundsRight 对应订阅，关闭自动续费/取消订阅。

备选路径：手机「设置」→「华为帐号」→「付款与账单」→「订阅」→ 管理 SoundsRight 订阅。

其他渠道：

  • Apple：设置 → Apple ID → 订阅 → SoundsRight；
  • Google Play：Play 商店 → 个人资料 → 付款和订阅 → 订阅 → SoundsRight。

退订操作由应用商店提供，步骤应简单便捷；我们不会在退订时设置不合理附加条件。若您在退订过程中遇到困难，请联系 soundsrightcn@gmail.com。

六、免费试用（如适用）

若应用提供限时免费试用（以应用内展示为准），试用期内不发生扣款；试用结束后如需转为付费订阅，须再次征得您的同意并按应用商店流程开通，不会静默转为自动续费。当前华为渠道版本以应用内实际展示为准。

七、与一次性「终身会员」的区别

终身会员（商品 ID：soundsright_english_lifetime）为一次性购买，不属于自动续费服务，付清后无周期性扣款。购买终身会员无需签署本自动续费条款，但仍建议阅读 《会员服务说明》。

八、服务变更与争议

  • 会员服务内容如有重大变更，我们将提前通过应用内公告或本页面更新等方式告知；若您不同意变更，可退订自动续费并在当期结束后停止使用；
  • 本协议未尽事宜，适用应用商店协议及中华人民共和国相关法律法规；
  • 联系我们：soundsrightcn@gmail.com，支持页面。

九、协议更新

我们可能适时修订本协议，修订版本将发布于本页面并更新生效日期。重大变更将通过应用内合理方式提示。若您继续使用自动续费服务，即视为接受修订；若不同意，请退订自动续费。
